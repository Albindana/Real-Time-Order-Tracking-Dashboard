The 30-second flow:
1. User places an order → POST /api/orders
2. API saves it & publishes an event to Redis, returns 201
3. A background worker subscribed to that channel receives it
4. The worker broadcasts over SignalR to every dashboard
5. The React UI updates instantly — no polling
